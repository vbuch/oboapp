Sofia Sans static Regular and Bold fonts for server-rendered social cards.
These include the Cyrillic glyphs used by the Bulgarian descriptions.

Source: https://github.com/lettersoup/Sofia-Sans
Files: fonts/ttf/Normal/SofiaSans-Regular.ttf and SofiaSans-Bold.ttf
Downloaded: 2026-11-12
License: SIL Open Font License 1.1, reproduced in OFL.txt.

The browser UI continues to use the installed @fontsource-variable/sofia-sans
package. These TTF files let the bundled next/og renderer work without
requesting fonts from an external service.
